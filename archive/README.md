# Archived TechShelf catalog

The previous TechShelf repository was a curated technical-book catalog, not the implementation of the new PDF reading application.

- [catalog.json](catalog.json) — original curated catalog, preserved unchanged.
- [SCHEMA.md](SCHEMA.md) — original catalog schema and CLI notes, preserved unchanged.

These files are historical reference material. They are not Shelf's current database schema or implementation contract. Any future catalog importer must be explicit and separately tested.
