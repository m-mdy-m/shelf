# Shelf — Product overview

Shelf is a reading workspace for PDF books, papers, manuals, and technical documents.

It brings four activities together:

1. **Read:** open local PDFs, navigate comfortably, search, and resume where you stopped.
2. **Annotate:** bookmark locations, highlight exact passages, and attach personal notes or reusable quotes.
3. **Understand:** ask an optional AI companion to explain, summarize, translate, or compare selected source material.
4. **Keep knowledge:** export reading notes and quotes, then build reviewable concepts and flashcards from what you read.

## Product promises

- Core reading and annotations work without a network connection.
- Documents stay local unless the user explicitly chooses a remote AI provider.
- Local and cloud AI are both supported; the provider and model can be selected per task.
- Verified AI citations link back to the source passage and page.
- Reading data is portable and does not require an account.
- Windows, macOS, Linux, Android, and iOS are designed for from the beginning; platform support is claimed only after target testing.

## What Shelf is not

Shelf is not a full PDF authoring suite, a cloud-only document manager, or a chatbot that invents page references. Its first priority is a fast, dependable reading experience.
